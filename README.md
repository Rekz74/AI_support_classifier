Интеллектуальная система классификации обращений пользователей

О проекте

Небольшой прототип системы, которая автоматически анализирует текст обращения пользователя и определяет:

- категорию обращения;
- приоритет обращения.

Идея проекта — упростить первичную обработку обращений в службе поддержки. Система может помочь автоматически распределять новые обращения между нужными направлениями.

Категории

Система использует следующие категории:

- Оплата
- Доставка
- Возврат
- Авторизация
- Техническая проблема
- Другое

Для каждого обращения также определяется приоритет:

- Низкий
- Средний
- Высокий

Как это работает

Для обработки текста используется классический подход машинного обучения:

текст обращения → TF-IDF → Logistic Regression → категория и приоритет

TF-IDF преобразует текст в набор числовых признаков, после чего модель Logistic Regression определяет наиболее подходящий класс.

В проекте используются две отдельные модели:

1. модель для определения категории;
2. модель для определения приоритета.

Данные

Для обучения использован небольшой подготовленный набор из 130 примеров обращений пользователей.

Данные разделяются на:

- 75% — обучение;
- 25% — тестирование.

Тестовая выборка содержит 33 обращения.

Результаты

На тестовой выборке получены следующие результаты:

| Задача | Accuracy |
|---|---:|
| Определение категории | 81.82% |
| Определение приоритета | 81.82% |

Для дополнительной оценки также рассчитываются precision, recall и F1-score.

Пример работы

Вход:

Я оплатил заказ, но деньги списались и заказ не появился

Результат:

Категория: Оплата
Приоритет: Высокий

Другой пример:

Как изменить номер телефона в профиле

Результат:

Категория: Авторизация
Приоритет: Низкий
